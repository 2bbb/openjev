# Public presentation research note

TypeSafe's public homepage uses a muted, looping two-terminal race as its primary speed demonstration. One terminal fills a typed batch of decisions while the comparison terminal remains at its request stage. The accompanying blog explicitly says this illustrates parallel typed outputs versus autoregressive strings, and notes the query is simplified and favorable to its model.

OpenJev's demo is original and contains no TypeSafe media. It borrows only the high-level presentation idea: make the computation shape visible, then place scope and caveats beside the result. It depicts one owned state evaluated against 21 criteria and calls itself an accelerated replay.

- [Exact homepage race referenced during review](https://framerusercontent.com/assets/g4FBJpKG573R4zYuoY3HLJIMCu4.mp4) — a 14.72-second, 1280 × 720 monochrome terminal comparison: 27 questions begin together, the typed batch completes while the token-generating comparison continues. Inspected only; not copied.

They were inspected only; neither is copied here.
- [Introducing System One Models & Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) — its “Side-by-side demonstration” section describes the intended contrast and caveats.
- [TypeSafe documentation introduction](https://docs.typesafe.ai/introduction) — describes mixed typed questions evaluated in parallel and in isolation.

The inspected homepage media uses a lo-fi desktop/window visual language. The original OpenJev page uses a separate design and no third-party media or external requests.
